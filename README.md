# Customer Support Ticket Priority Prediction

## About

This project predicts the priority of customer support tickets using Machine Learning.

## Objective

To classify support tickets based on priority and help support teams handle important issues faster.

## Technologies Used

* Python
* Machine Learning
* Pandas
* Scikit-learn

## Features

* Predicts ticket priority
* Classifies tickets based on urgency
* Improves customer support efficiency

## Conclusion

This project automates ticket prioritization and helps improve customer service.
